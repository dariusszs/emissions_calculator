# CO2 Emission Calculator

A simple, interactive CO2 calculator built for the Coral project. It calculates estimated emissions for car and flight travel, fairly splits car journeys among passengers, and shows how many trees are needed to offset them on a monthly and yearly basis.

## Features
- **Transportation Mode Selection:** Driving or Flying.
- **Passenger Calculation:** Automatically splits CO₂ emissions for car rides based on the specified number of passengers.
- **Tree Comparison:** Displays how many trees are needed to absorb the emissions over a month or a year.

## How to Run It
1. Download or clone this repository.
2. Open the `index.html` file by double-clicking it in any web browser (Chrome, Safari, Firefox, etc.).
3. Alternatively, you can open the [Live Demo](https://dariusszs.github.io/emissons_calculator/) in your browser.
